# Platform Engineer, Example Retail Cloud

Example Retail Cloud (a fictional company) is rebuilding its data pipeline and the services that read from it.

## What you will do

- Design, build and run backend services.
- Work with product and data teams to ship changes safely.

## What we are looking for

- Event-driven systems; Kafka experience is a plus.
- Leading a small team through a multi-month project.
- Writing onboarding material for new engineers.
- Building customer-facing interfaces in React.
- Solid Java and the Spring Boot ecosystem.

Candidates who do not meet every requirement are still encouraged to apply.
